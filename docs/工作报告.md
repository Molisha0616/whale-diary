## 6. 数据模型（SQLite v6）

| 表 | 关键字段 |
|---|---|
| entries | day、created_at、body、type(entry/plan/message)、plan_state |
| media | entry_id、kind(photo/video)、path |
| comments | entry_id、created_at、body |
| messages | kind(daily/weekly/monthly/yearly/plan_unconfirmed)、title、body、read |
| reports | kind、period_start／end、body |
| settings | key／value（字号、背景、接口地址等，不含 key） |

迁移：v1 建表 → v2 messages → v3 read 列 → v4 media → v5 settings → v6 reports。

## 7. 关键决策（为什么这么做）

1. **全本地优先**：记录、媒体、备份都在手机上；只有报告生成走网，且直连 DeepSeek 官方域名，中间没有我方服务器。
2. **API key 只进 KeyStore**：不写代码、不进日志、不进备份；换机要重填，这是安全换来的代价。
3. **报告定时改成「打开时补生成」**：HyperOS 会杀后台，1:05 准点做不到可靠，换算成打开即补，一天不会重复。
4. **语音模型不打包**：1.3G 塞不进 APK，改成导入 zip＋本地解压，APK 从 285MB 降到 58MB。
5. **视频 15 秒上限**：存储可控；超 15 秒不做裁剪，直接截断录制。
6. **恢复是覆盖式**：先删后插，简单可预期；冲突合并留作后续。
7. **图标用自适应图标**：前景缩到画布 68%，圆形/圆角遮罩不切脸。

## 8. 踩过的主要坑

| 坑 | 解法 |
|---|---|
| Flutter 镜像挑到 2019 年的 1.9.1 | 按版本号排序取最新稳定版 |
| `git fetch --tags` 卡住首次启动 | 把 SDK remote 指到本地空仓库，fetch 秒回 |
| Gradle 首次构建卡在 Maven Central | 阿里云镜像 + 短超时；`-all` 换 `-bin` |
| Worker 报 `ClassNotFoundException` | 把 TEMP/TMP 指到 `D:\tmp`（避开中文路径） |
| `share_plus` 12 要 Kotlin 2.x | 降到 7.2.2 |
| `flutter_secure_storage` 要 minSdk 23 | minSdk 从 21 提到 23 |
| debug→release 签名不同，不能覆盖装 | 先拉数据、卸载、装 release、用备份恢复 |
| 语音模型官方站下载 16KB/s | 换 GitHub raw 镜像，仍慢则用户手动下载 |

**踩过的坑与结论**

| 情况 | 结论 |
|---|---|
| PC 直连 GitHub HTTPS 推代码 | `Empty reply from server`／`SSL_ERROR_SYSCALL`，不通 |
| PC 走 SSH 443（`ssh.github.com:443`） | **通**，认证成功后可直接推 |
| Gitee 镜像到 GitHub | 需要绑定 GitHub 账号，主人不愿把两个账号焊在一起，**放弃镜像**，改为双 remote 直推 |
| Edge 代理插件 | 只能代理浏览器，管不到 git 进程，无用 |
| 令牌与密钥 | GitHub 令牌只在网页用、不进文件；keystore 与 key.properties 已进 `.gitignore`，全历史扫描确认无泄漏 |

## 11. 已知限制

1. 启动仍是白屏（按你要求先不动）。
2. 恢复是整库覆盖，没有冲突合并。
3. 视频只验证了常见编码，H.265 之类可能解不了。
4. 语音模型需要手动导入；换机／卸载后要重导。
5. 报告需要 key＋联网；没网时静默跳过。
6. 日报只在打开 App 时补生成，不是后台准点推送。
